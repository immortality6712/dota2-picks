# Разбор от ИИ через Google Gemini

Сайт умеет разбирать матчи с помощью Gemini. Ключ Gemini нельзя класть в страницу, его сразу украдут.
Поэтому между сайтом и Google стоит маленький посредник на Cloudflare Workers. Ключ хранится там.
Всё бесплатно, настройка занимает около 10 минут.

Пока посредник не настроен, сайт пользуется бесплатным Pollinations. Если Gemini не ответит, сайт тоже переключится на Pollinations.

## 1. Ключ Gemini

1. Откройте <https://aistudio.google.com/apikey> и войдите в аккаунт Google.
2. Нажмите **Create API key** и скопируйте ключ (начинается с `AIza…`).
3. Никому его не отправляйте и не вставляйте в файлы репозитория.

## 2. Воркер Cloudflare

1. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатный план).
2. **Workers & Pages → Create → Create Worker**, придумайте имя, например `dota2-ai`, и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё, вставьте содержимое файла [`gemini-proxy.js`](gemini-proxy.js) и нажмите **Deploy**.
4. Вернитесь к воркеру: **Settings → Variables and Secrets → Add**:
   - Type: **Secret**, Name: `GEMINI_API_KEY`, Value: ваш ключ из шага 1.
   - Если сайт открыт не на `https://immortality6712.github.io`, добавьте ещё переменную `ALLOWED_ORIGINS` с адресом сайта.
   - Модель по умолчанию — `gemini-2.5-flash`. Другую можно задать переменной `GEMINI_MODEL`.
5. Сохраните (**Deploy**).
6. Скопируйте адрес воркера вида `https://dota2-ai.ИМЯ.workers.dev`. Открыв его в браузере, вы должны увидеть `{"ok":true,…,"key":true}`.

## 3. Подключить к сайту

Впишите адрес воркера в `index.html` в строку

```js
const AI_PROXY = '';
```

например `const AI_PROXY = 'https://dota2-ai.ИМЯ.workers.dev';`. Адрес не секретный, его можно просто прислать в чат.

## Ограничения

- С одного IP — не больше 6 запросов в минуту, чтобы чужие не израсходовали бесплатный лимит Gemini.
- У бесплатного плана Gemini свои дневные лимиты. Когда они кончаются, сайт переключается на Pollinations.
- На бесплатном плане Google может использовать запросы для улучшения своих моделей. В запрос уходит только
  статистика матча из OpenDota (она и так публичная), без личных данных.
